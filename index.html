📝 T-PWEB Notes App

Tugas Kuliah Pemrograman Web

⚠️ Catatan Penting: Ini adalah aplikasi PHP dengan database MySQL yang tidak dapat berjalan langsung di GitHub Pages. GitHub Pages hanya mendukung file statis (HTML, CSS, JS). Untuk menjalankan aplikasi ini, Anda perlu mengatur server lokal dengan PHP dan MySQL.

📋 Tentang Proyek

Sebuah aplikasi web sederhana untuk membuat catatan (notes) dengan fitur CRUD (Create, Read, Update, Delete). Aplikasi ini dibangun menggunakan PHP dan MySQL sebagai tugas kuliah pemrograman web.

✨ Fitur

  • Sistem login dan registrasi pengguna
  • Membuat catatan baru
  • Menampilkan semua catatan pengguna
  • Mengedit catatan yang sudah ada
  • Menghapus catatan
  • Pencarian catatan real-time
  • Password hashing untuk keamanan

🛠️ Teknologi yang Digunakan

PHP MySQL HTML5 CSS3 JavaScript

🚀 Cara Menjalankan

  1. Clone repository ini:
    git clone https://github.com/farelyudapratama/T-PWEB.git
  2. Install XAMPP atau server lokal lain yang mendukung PHP dan MySQL
  3. Pindahkan folder project ke direktori htdocs (untuk XAMPP)
  4. Buat database MySQL dengan nama notes-1
  5. Buat tabel users dengan kolom:
    - id (INT, AUTO_INCREMENT, PRIMARY KEY)
    - username (VARCHAR)
    - password (VARCHAR)
  6. Buat tabel notes dengan kolom:
    - sno (INT, AUTO_INCREMENT, PRIMARY KEY)
    - user_id (INT)
    - title (VARCHAR)
    - description (TEXT)
  7. Jalankan Apache dan MySQL di XAMPP
  8. Akses aplikasi melalui http://localhost/T-PWEB/

📂 Struktur File

  • index.php - Halaman utama untuk menampilkan dan menambah catatan
  • login.php - Halaman login
  • signup.php - Halaman registrasi
  • db.php - Konfigurasi koneksi database
  • edit.php - Modal untuk mengedit catatan
  • delete.php, deleteNote.php, deleteUser.php - Handler untuk menghapus data
  • style.css, loginAndSingup.css - Styling
  • script.js - JavaScript untuk interaktivitas

🔒 Keamanan

Saat ini aplikasi menggunakan password_hash() untuk hashing password. Untuk versi production, disarankan untuk menambahkan:

  • Prepared statements untuk mencegah SQL Injection
  • CSRF protection
  • Input validation yang lebih ketat
  • HTTPS untuk koneksi aman
